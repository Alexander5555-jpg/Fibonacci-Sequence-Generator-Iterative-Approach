# Fibonacci Sequence Generator – Iterative Approach

#### The program generates a Fibonacci sequence using an iterative approach. The user is asked to enter a positive integer, which determines how many numbers of the Fibonacci sequence will be displayed.

#### The program checks whether the entered value is valid. If the user enters a number that is less than or equal to zero, or enters something that is not an integer, an appropriate error message is displayed, and the program asks for input again.

#### Once a valid number is entered, the program generates and prints the Fibonacci sequence using a for loop and two variables (a and b). Each new number is calculated as the sum of the previous two numbers.
